# 🚦 E-Challan System

The **E-Challan System** is a full-stack web application designed to manage and automate traffic challans digitally.  
It helps traffic authorities generate challans online and allows users to view and pay challans easily.

This project is built using **React.js** for the frontend, **Node.js & Express.js** for the backend, and **SQL** as the database.

---

## 📌 Features

### 👮 Admin / Traffic Police
- Login authentication
- Create and issue e-challans
- View all issued challans
- Manage vehicle and user records

### 🚗 User
- View challan details using vehicle number
- Check challan status (paid / unpaid)
- Online challan payment (can be integrated)
- View challan history
